SEMINARIO DE INVESTIGACIÓN II — PAQUETE DE ENTREGA
==================================================

Tema:
Evaluación de la estabilidad e interpretabilidad de los determinantes predictivos del precio de Bitcoin mediante Machine Learning y Deep Learning bajo diferentes condiciones de mercado.

ARCHIVOS PRINCIPALES
--------------------
1. seminario_bitcoin.pdf
   Documento final compilado (18 páginas).

2. seminario_bitcoin.tex
   Fuente LaTeX editable.

3. referencias.bib
   Bibliografía utilizada por el documento LaTeX.

4. presentacion_bitcoin.html
   Presentación HTML5 autocontenida, sin dependencias externas.

ANTES DE SUBIR
--------------
Solo quedan dos campos administrativos deliberadamente sin inventar en la portada:
- [Completar institución]
- [Completar docente]

Edítelos en seminario_bitcoin.tex y vuelva a compilar.

COMPILACIÓN LATEX
-----------------
Desde la carpeta del proyecto:
  latexmk -pdf seminario_bitcoin.tex

PRESENTACIÓN HTML5
------------------
Abra presentacion_bitcoin.html en Chrome/Chromium/Firefox/Edge.
Controles:
- Flecha derecha / PageDown / Espacio: siguiente diapositiva
- Flecha izquierda / PageUp: anterior
- Home / End: inicio / final
- F11: pantalla completa del navegador

La presentación es autocontenida: no necesita Internet ni CDN.
Para entregar una copia estática adicional, puede usar Imprimir > Guardar como PDF desde el navegador.

NOTA METODOLÓGICA
-----------------
El informe distingue explícitamente importancia predictiva de causalidad, evita comparar métricas incompatibles entre papers y deja la elección final ML vs DL para la etapa empírica, conforme a la guía.
